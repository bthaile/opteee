# Is Value Investing Dead?

## Summary

This analysis examines whether value investing—the practice of buying securities trading below intrinsic book value—remains viable after the post-2007 performance collapse. The speaker documents a structural breakdown in traditional value metrics, showing that all major value measurement systems shifted simultaneously around 2007, suggesting the premium itself may have fundamentally changed rather than merely underperformed cyclically.

## Key takeaways

- **Book value as a metric is broken** [00:00] — Traditional book-value-based valuation no longer functions as intended; the measurement system itself has failed to track what it's supposed to measure.
- **Post-2007 value premium collapse is extreme** [00:00] — The underperformance range of −7% to +4.4% annually is far outside historical norms and cannot be explained by standard premium theory.
- **Synchronized regime shift across all value systems** [00:00] — All four major value measurement methodologies shifted at the same time around 2007, indicating a structural market change rather than isolated metric failure.
- **Historical context matters** [00:00] — The pre-2007 era looks fundamentally different from the post-2007 period, suggesting a regime break rather than cyclical underperformance.

## Regime / context

This analysis addresses the post-2007 financial crisis era, when traditional value metrics ceased to function as historical models predicted. The structural breakdown in book-value-based valuation systems suggests a permanent regime change in how markets price value, rather than a temporary cyclical downturn in value-factor performance.
