# Relative Value

Relative value is a strategy that exploits asymmetries and mispricings across the volatility surface or term structure rather than making directional bets on price movement. Traders using this approach identify where implied volatility differs across strikes and expirations for the same underlying, then construct positions to profit from those relative dislocations. As part of a diversified trading toolkit, relative value serves as one of several uncorrelated strategies—alongside carry and momentum—that professional and serious retail traders build to achieve sustainable returns across different market regimes.
